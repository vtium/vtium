Cullet Mono: notices

Cullet Mono is vtium's outline version of the Terminus font, with Nerd Fonts' icons added. vtium builds it from Terminus (TTF) 4.49.3 with Nerd Fonts' font patcher 3.4.0, as tools/cullet-mono/README.md in vtium's source describes. This file lists each part of Cullet Mono with its copyright, its license, and the attribution that license asks for. The other files in this folder hold the full license texts it names.

Cullet Mono as a whole is a Modified Version of Terminus (TTF) under the SIL Open Font License, Version 1.1 (OFL-1.1). Its full text is in terminus-ttf-COPYING.txt.


Terminus (TTF) 4.49.3
=====================

The font Cullet Mono is made from: TerminusTTF-4.49.3.ttf and TerminusTTF-Bold-4.49.3.ttf, from https://files.ax86.net/terminus-ttf/.

Copyright (c) 2010 Dimitar Toshkov Zhekov, with Reserved Font Name "Terminus Font".
Copyright (c) 2011-2023 Tilman Blumenbach, with Reserved Font Name "Terminus (TTF)".

License: OFL-1.1, in terminus-ttf-COPYING.txt, a verbatim copy of the release's COPYING file.

The OFL forbids a Modified Version to use a Reserved Font Name, so the patched font is named Cullet Mono. It uses neither "Terminus Font" nor "Terminus (TTF)" as its name, and it stays under the OFL-1.1. vtium treats the bare word "Terminus" as reserved too, so no name of Cullet Mono holds it, not even the names of its bitmap strikes. Each face's copyright notice and description still credit Terminus Font and Terminus (TTF) as its source.

The icon sets
=============

The patcher adds the glyph sets below, each scaled and placed to fit one character cell of Cullet Mono (the patcher's --mono option). Some sets move to the code points of Nerd Fonts' layout. Each entry gives the set's name as the patcher's log gives it, its source, its copyright, and its license as Nerd Fonts' license-audit.md lists it. Where the patcher's archive carries the set's license file, this folder holds a verbatim copy of it. MIT.txt holds the MIT License's permission notice for the MIT sets whose license file the archive lacks.

Font Logos, left out
====================

Cullet Mono leaves out the patcher's Font Logos set, the logos of operating systems and projects at U+F300 to U+F385, because Nerd Fonts' license-audit.md lists it as unlicensed. vtium draws those characters from a Nerd Fonts font that the system has installed, such as Symbols Nerd Font Mono.
