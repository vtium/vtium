# vtium's goldens

The goldens of vtium's own tier 2 screens, which the C reference's tier 2 has none for. Each is reviewed vtium output that judges vtium. The C reference drew every one but the `osd-`, `notice-` and `notices-` goldens, the two `small-` goldens, the two `vitrified-` goldens and `emoji-rgba`, with a program built from kmscon `b1f7a7c5df563f3378584db7298753848a7a9a13` and libtsm `3ec40dc7a185dea1cd7e1252d4215939af1977fb`, the commit that kmscon's `subprojects/libtsm.wrap` pinned, through libtsm, bbulk with the unifont backend and drm2d's blend; that program is retired (vtium/vtium#111). vtium drew the two `osd-` goldens without a size in their names (vtium/vtium#169), the overlay goldens whose names end in `-800x480` or `-3840x540` (ADR-1401 D5, D7), the two `small-` goldens (vtium/vtium#75), the two `vitrified-` goldens, from sets built as `vtium-vitrify create` builds them (vtium/vtium#126), and `emoji-rgba` (vtium/vtium#23), behaviour only vtium has. A golden added here stays in `../provisional.tsv` until the operator has reviewed it.

| Each golden whose name ends in `-800x480` or `-3840x540` | The overlay goldens are every message bar vtium draws, at two sizes over one shell session: a login, `ls` with `bin` bold blue and `run.sh` bold green, `cat notes.txt` with `back up the laptop` in red, `uname -sr` and a prompt. The `-3840x540` goldens are the top band of a 7680x2160 display in its 24x54 cell, 3840x540 as 160 by 10 cells, unifont tripled on each cell's bottom 48 rows, a box's edge 6 pixels wide and its text 19 down and 18 in, each line adding 54 pixels to a box 92 tall. Every box spans the display's width. The session's rows below it are as the terminal drew them. |
