# tier 2's goldens

The goldens of tier 2's screens. Each judges vtium. Most were first drawn by a program that is retired now (vtium/vtium#111) and are kept as they were drawn. vtium drew the outline goldens from the test font set of outline fonts (ADR-1503 D9), the two `osd-` goldens without a size in their names (vtium/vtium#169), the overlay goldens whose names end in `-800x480` or `-3840x540` (ADR-1401 D5, D7), the two `small-` goldens (vtium/vtium#75), the two `vitrified-` goldens, from sets built as `vtium-config create` builds them (vtium/vtium#126), `emoji-rgba` (vtium/vtium#23), the two `link-hover-` goldens and the three `link-overlay-` goldens (ADR-1002), behaviour only vtium has. A golden added here stays in `../provisional.tsv` until the operator has reviewed it.
