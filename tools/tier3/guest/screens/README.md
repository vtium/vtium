Each `NAME.sh` here draws one tier 3 screen, run by `t3 NAME` in the guest after the console is cleared, and one page of the local VT demo ([docs/fork/demo.md](../../../../docs/fork/demo.md)), whose `fork/demo/sections/NN-NAME.sh` is a symlink to it or a wrapper that runs it. Its leading comment lines are the screen's caption on the run and comparison pages. A `# look-for:` line says what correct looks like and a `# wrong-looks-like:` line what a defect looks like; the demo's footer shows both, and the run page shows them with the caption.

The scripts also run on the host, when `t3_evaluate.py` evaluates a run: their output, with colours removed, names the text drawn in each differing region of a comparison. So a script prints its screen top to bottom, reads no input, finishes at once, and uses no escape sequence other than colours (SGR). A cursor move, a tab or a character-set switch leaves the pages without that screen's text. `wide-margin` is the one screen that does so on purpose: its cases sit at the screen's real right edge and wrap there, so its printed lines could not name its rows anyway.

A `# screen-text: none, <reason>` line says a script's printed lines are not its rows, so the host does not run it for its text; `s1-scroll` prints 500 000 lines of which the screen keeps the last. A benchmark screen (`BENCHMARKS` in `t3_evaluate.py`) also reports its measured window on the event port as `T3-BENCH NAME start=S end=E KEY=N...`, the keys in any order (see the tier 3 README's Benchmarks); it has no demo page.

A `# kit:` line names the VT demo's review kit the page belongs to (`sixel` or `kitty`; text without one), and stays out of the caption. A screen may be followed by key chords, each a case of its own (`KEYED` in `t3_evaluate.py`), as `photo-scroll` is by Shift+PageUp and Shift+PageDown. The sixel acceptance screens (`photos`, `photo-scroll`, `mpv-sixel`, `tmux-2x2`, `tmux-3x3`) share `acceptance.inc`, which names the programs they need and says what to install when one is missing, and the photograph `photos` and `photo-scroll` draw (`photo/street-sunset.jpg`, the operator's, licensed CC BY 4.0 as `photo/LICENSE` says), and report their counts on the event port that `t3` names in `T3_EVENTS`; run anywhere else, as on the VT demo's pages, they print the counts under the page instead.
