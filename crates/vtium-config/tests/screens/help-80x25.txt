 Tab moves to the next view, and Shift-Tab moves to the one before, wherever
 the selection is. The arrow keys move inside a view. While a card, a list, the
 draft's text, the form for a new font set, or a value you are typing is open,
 Tab does nothing until you close it with Esc. While a question waits for your
 answer, Tab answers no.

 Flow shows how the console is set up, from the displays to the input devices:
 each display, the rule that sends it to a head (a screen with its own
 consoles), the head and its look (its font and size), and each input device
 with the rule that sends its typing to a head.
     ↑↓←→ move  Space pick  Enter open  a add path  e revise  v view file  Esc
     clear  i install  o restore  n new  p preview  t trial  PgUp PgDn scroll
     q quit

 Looks lists the console's font sizes, automatic first, with a preview of each.
 Later it will manage the looks, each a font set and a size.
     Enter choose  Tab next view  i install  q quit without installing

 Fonts lists the font sets (frits) and the built-in fonts, with any font files
