   Add this font set to the install

 A font set combines a text font with fonts for the other roles. vtium tries
 the fonts in the order of the rows, and each later font supplies the
 characters the fonts before it lack. Enter on a role lists the active fonts
 that can fill it, and the layers of that role. A layer is a group of fonts for
 scripts, symbols, emoji or the fallback. To use a font the list lacks,
 activate it in the Fonts tab, or pick Other… and type its name. If you leave
 Name empty, the name comes from the text font.
