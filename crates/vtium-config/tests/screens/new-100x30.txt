   Add this font set to the install

 A font set (frit) combines up to three fonts. Name each font by its family, such as JetBrains
 Mono, or as a frit file names it, such as kbd:ter-v16n. Each later font supplies the characters
 the fonts before it lack. Character cell is WIDTHxHEIGHT in pixels and Size is in points; leave
 both empty to use the fonts' own size. If you leave Name empty, the name comes from the first
 font.
