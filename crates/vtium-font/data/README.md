# vtium-font data

| Path | What it is |
|---|---|
| `unifont.hex` | GNU Unifont 17.0.03, the unifont-all build: every glyph as `codepoint:bits`, 32 hex digits for an 8x16 glyph and 64 for a 16x16 one, planes 0-3, 14 and 15. `build.rs` packs it into the binary, and `tests/digests/unifont.tsv` holds the glyphs it draws. |
| `OFL-1.1.txt` | The SIL Open Font License 1.1, as unifoundry.com publishes it with Unifont. |
| `unscii-8.hex` | Unscii 2.1's 8x8 font, `unscii-8.hex` from <http://viznut.fi/unscii/unscii-8.hex>, fetched 2026-10-28, SHA-256 `03094f7fbab7085cf6a6b624cee61e47e71ce5d0c2f308c2f4436afdc17f776c`, the hash ADR-1200 D7 pins: 3,191 glyphs as `codepoint:bits`, 16 hex digits for an 8x8 glyph and 32 for the one 16x8 glyph, U+0000. The `.hex` is a build output the source tarball does not hold, so the published file is pinned by its hash. `build.rs` packs it into the built-in `unscii-8` set. In the public domain. |
| `builtin-chars.txt` | The list of characters that vtium's built-in font, "vtium built-in", holds: printable ASCII, Latin-1, the ellipsis, the four arrows that name a chord's arrow keys, box drawing and blocks, and the focus mark's circles. `build.rs` cuts each of the font's three strikes from its source with this list, and a test fails when vtium's own text uses a character outside it. |
| `ter-u16n.bdf`, `ter-u32n.bdf` | Terminus Font 4.49.1's regular 8×16 and 16×32 BDF files, unchanged, from `terminus-font-4.49.1.tar.gz` (<https://downloads.sourceforge.net/project/terminus-font/terminus-font-4.49/terminus-font-4.49.1.tar.gz>, SHA-256 `d961c1b781627bf417f9b340693d64fc219e0113ad3a3af1a3424c7aa373ef79`). Their own SHA-256 sums are `5197662b22bf9f3e68d4af9f969a7fefa3edae40dd82ae969a147381130fb4ae` and `5ad01972d58adfee75077e2c65ba5947e260043031664cb8ad8f98b5473b23a4`. `build.rs` cuts the built-in font's 8×16 and 16×32 strikes from them, and the 8×8 strike from `unscii-8.hex`. Terminus lacks ten characters of the list, U+2504 to U+2507, U+254C to U+254F, U+2594 and U+2595, which vtium's sprites draw. Under the SIL Open Font License 1.1, with the Reserved Font Name "Terminus Font", so the cut strikes are named "vtium built-in". |
| `unscii.txt` | Unscii's notes from `unscii-2.1-src.tar.gz` (<http://viznut.fi/unscii/unscii-2.1-src.tar.gz>, SHA-256 `4d1215d495e49d005ae70828ec1529e997049b9a7f152b9439d78c7e70c65b57`), unchanged: "Everything made by me (viznut) is in the Public Domain.", and only `unscii-16-full`, which vtium does not use, falls under the GPL. |

To check the Terminus files, download the archive, check its SHA-256, and compare the two files with the archive's: `tar -xzf terminus-font-4.49.1.tar.gz` and then `cmp terminus-font-4.49.1/ter-u16n.bdf crates/vtium-font/data/ter-u16n.bdf`, and the same for `ter-u32n.bdf`.
