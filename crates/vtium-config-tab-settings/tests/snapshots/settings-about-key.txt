Settings › Fonts and text › font-name

The console's font.

The value is the name of a font set (a frit file, `NAME.vtfrit` in `/etc/vtium/fonts`). It can also be the name of a kbd console font, or the absolute path of a font file, such as a PSF, BDF or TrueType font; vtium then uses that one font.

When unset, vtium uses the font from vconsole.conf, or else the font set `terminus`. If vtium cannot find the font, it uses its built-in font and logs why.

  Default    unset
  Now        unset, default
