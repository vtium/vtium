# SGR 4 and 24: underline

| Sequence | What it does |
|---|---|
| `CSI 4 m` | single underline |
| `CSI 24 m` | no underline |

## Parameters

- `Pm`: One or more SGR codes separated by `;`. vtium applies them in order, so `CSI 1 ; 4 m` sets bold and underline. The default is 0, which resets every attribute.

## What vtium does

vtium draws a single line under the text that follows SGR 4, in the text's color unless SGR 58 sets an underline color. SGR 24 removes every underline, whatever its style.

## Status

- **Status:** supported. vtium implements this as the specifications below define it.
- **Why:** editors, man pages and spell checkers underline text.
- **Specifications:** [xterm's control sequences](https://invisible-island.net/xterm/ctlseqs/ctlseqs.html)
