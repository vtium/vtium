# Find out what went wrong

This guide finds out why vtium does not do what you expected, from the VT itself, from `vtium console status` and from vtium's log.

The steps are, for now, in [managing-vtium.md](managing-vtium.md#troubleshooting):

- [Reading vtium console status](managing-vtium.md#reading-vtium-console-status), which says what each VT runs at boot, when you switch to it, and now.
- [A font that does not load](managing-vtium.md#a-font-that-does-not-load).
- [A VT that shows a getty](managing-vtium.md#a-vt-that-shows-a-getty), the kernel's plain login prompt, where you expected vtium.
- [A VT that shows nothing](managing-vtium.md#a-vt-that-shows-nothing).
- [vtium console refuses a VT](managing-vtium.md#vtium-console-refuses-a-vt).

If none of these explains it, [the issue tracker](https://github.com/vtium/vtium/issues) is where to report it.
