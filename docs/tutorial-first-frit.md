# Your first frit

This tutorial is coming. In it you will run `vtium config` in a vtium console, move the highlight through the fonts while the live console changes to each one, save your choice, and see it at vtium's next start. A frit, or font set file, is the short text file, `/etc/vtium/fonts/NAME.vtfrit`, that names the fonts vtium draws from.

Until it is written, [Choose a font](fonts.md) lists the steps, and [Try vtium on one VT](tutorial-try-vtium.md) gets vtium running on a VT to try them on.
