# Releases

Each release has a page that says what it adds, changes and fixes. The newest release comes first. Every release so far is an alpha, a pre-release for people who want to try vtium and report what they find.

The files of a release, such as its source archive and the archive of its dependencies' source, are on its page on GitHub.

| Release | Date | What it is about | Files |
|---|---|---|---|
| [0.1.0-alpha.12](0.1.0-alpha.12.md) | 2026-11-27 | Most of vtium running without root, scrolls that move the picture on the CPU, and fonts named by their path. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.12) |
| [0.1.0-alpha.11](0.1.0-alpha.11.md) | 2026-11-22 | Underlines that skip the ink of descenders, a Looks tab that assembles a look, and drafts that keep font set changes until you install them. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.11) |
| [0.1.0-alpha.10](0.1.0-alpha.10.md) | 2026-11-20 | Colors that fit the reader: corrections for color blindness, a brightness floor for dark text, and light color schemes such as Sunny. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.10) |
| [0.1.0-alpha.9](0.1.0-alpha.9.md) | 2026-11-17 | Double-size lines and kitty's sized text, programming ligatures, font sets that name the fonts they lack, and a login picture. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.9) |
| [0.1.0-alpha.8](0.1.0-alpha.8.md) | 2026-11-14 | Font sets for scripts that need more room, such as Indic and Arabic scripts, and a VT switch that no longer waits for slow display work. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.8) |
| [0.1.0-alpha.7](0.1.0-alpha.7.md) | 2026-11-12 | The VTs: a first install gives vtium the free VTs, vtium starts on them at boot, and each head can have VTs of its own. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.7) |
| [0.1.0-alpha.6](0.1.0-alpha.6.md) | 2026-11-07 | Text: right-to-left scripts, ink that reaches past its cell, and fonts that line up. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.6) |
| [0.1.0-alpha.5](0.1.0-alpha.5.md) | 2026-11-05 | The GPU: vtium can render each frame through it. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.5) |
| [0.1.0-alpha.4](0.1.0-alpha.4.md) | 2026-11-04 | The documentation site, and `vtium-config report`, which gathers what a bug report needs. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.4) |
| [0.1.0-alpha.3](0.1.0-alpha.3.md) | 2026-11-04 | A VT that wakes again after a desktop held the display, and kitty graphics sent in pieces. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.3) |
| [0.1.0-alpha.2](0.1.0-alpha.2.md) | 2026-11-03 | Images, decoded by a sandboxed helper, and the font tool's new name, `vtium-config`. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.2) |
| [0.1.0-alpha.1](0.1.0-alpha.1.md) | 2026-11-02 | vtium's first pre-release. | [On GitHub](https://github.com/vtium/vtium/releases/tag/v0.1.0-alpha.1) |

A release's page links the pages of this site as they are today. The notes of alpha.1 to alpha.3 link vtium's documentation on GitHub as it was at that release.
